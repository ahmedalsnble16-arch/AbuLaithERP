# نظام أبو ليث ERP

نظام محاسبي وإداري ومخزني وإنتاجي متكامل لمعمل أبو ليث لإنتاج الكيك والنواشف.

---

## 📋 المميزات

- ✅ يعمل بدون إنترنت (Offline First)
- ✅ مزامنة تلقائية عند توفر الإنترنت
- ✅ تطبيقات مستقلة حسب صلاحيات المستخدمين
- ✅ إدارة الإنتاج والمخزون والمعرض والموزعين
- ✅ تقارير شاملة وكشف مقارنة
- ✅ واجهة عربية بالكامل RTL

---

## 👥 المستخدمون

| المستخدم | الصلاحيات |
|----------|-----------|
| المدير العام | جميع الصلاحيات |
| مدير الإنتاج | الإنتاج وكشف المقارنة والمواد الخام |
| مدير المخزن | مخزن الإنتاج والمواد الخام والجرد |
| مدير المعرض | المبيعات والمعرض والمصروفات |
| مدير الخزنة | الخزنة والمصروفات وحسابات العمال والموردين |
| مدير الموزعين | تحميل وتصفية الموزعين |

---

## 🛠️ التقنيات المستخدمة

- **Flutter** - تطبيقات الهاتف
- **SQLite** - قاعدة بيانات محلية
- **Node.js + Express** - الخادم المركزي
- **PostgreSQL / SQLite** - قاعدة بيانات الخادم
